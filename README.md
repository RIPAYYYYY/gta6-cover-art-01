ViceFrame is an offline cover-art maker: drop in your own photos, arrange them across a multi-panel poster layout (hero split, top story, grid, trio, six pack, full bleed — or one photo spread across every panel), crop and zoom each panel by dragging, wash the art in a Vice City sunset or neon colour grade, letter your caption in bold poster type with a kicker line, and export a share-ready PNG at 1080 × 1080, 1080 × 1350 or 1920 × 1080. It is a static web app with no build step and no network requests; photos are read on your own machine and never uploaded. All art, lettering and code are original — the three bundled sample photos are AI-generated illustrations, and the lettering is drawn with built-in system fonts.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. To produce the hand-in output instead, run `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`, which copies `app/` and `screenshots/` to `out/` and writes `out/dossier.json`.
